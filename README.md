# homebrew-tap

```sh
brew install --cask ChinmayyK/tap/link-all
```

macOS 13+, Apple Silicon. Link All isn't notarized yet: on first launch open **System Settings › Privacy & Security** and click **Open Anyway**.

```sh
brew install --cask ChinmayyK/tap/streamdisk
```

StreamDisk: macOS 15+, Apple Silicon. The cask clears the quarantine flag, so there's no Gatekeeper prompt.
